# Car/Bike Driving Game (Pygame + OpenCV)

Top-view endless driving game with traffic, coins, shield
power-up, levels, and optional webcam head-steering.

## Features
- Car and Bike modes, 3 road themes
- Increasing difficulty, high score saving
- Webcam steering using OpenCV face detection

## Run
pip install pygame opencv-python
python main.py

## Controls
Arrow keys: steer | P: pause | V: vehicle | T: theme | C: webcam
